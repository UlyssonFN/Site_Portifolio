Dúvidas

Perguntas Frequentes

Precisa instalar algo no computador?
Não. O sistema é 100% online, acessível por qualquer navegador. Basta ter internet para usar em qualquer dispositivo.
Meus dados ficam seguros?
Sim. Os dados são armazenados na Oracle Cloud com backup automático, criptografia e histórico completo de operações.
Posso usar em mais de um computador ao mesmo tempo?
Sim. O sistema é multiusuário e permite acessos simultâneos com perfis de permissão diferentes por função.
O sistema pode ser personalizado para meu negócio?
Sim. Por ser desenvolvido internamente pela DataStock, adaptações e funcionalidades específicas podem ser desenvolvidas sob demanda.
Como funciona o suporte?
O suporte é prestado diretamente pela equipe DataStock via WhatsApp e e-mail, com SLA definido conforme o plano contratado.
